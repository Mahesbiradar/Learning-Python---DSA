# Learning Python — DSA

A daily practice log for learning Data Structures & Algorithms in Python, built as a structured, day-by-day drilling system rather than a one-off collection of solutions.

## Preview

- **33+ days** of practice logged so far, each with a notes file (`DAY_XX.md`) and a matching solutions file (`DAY_XX_SOLUTIONS.py`)
- Topics progress from fundamentals into patterns such as Frequency Sorting, Prefix Sum & Running State Tracking, Sliding Window, and Binary Search
- **30-DAY_CONSOLIDATED_DSA_AUDIT_FINAL.md** — a full audit/review after the first 30 days
- **PATTERNS.md** — recurring problem-solving patterns extracted from daily practice
- **ROADMAP.md** / **STATUS.md** — the plan and current progress

## What's Inside

- `Daily_Work/` — one notes file plus one solutions file per day (Day 08 onward), organized by week
- `Myfiles_old_week_1_2/` — earlier work from weeks 1–2
- `_archive_original/` — archived original material
- `PATTERNS.md` — a running reference of DSA patterns (sliding window, prefix sum, binary search, etc.)
- `PROMPTS.md` — prompts/templates used to structure daily practice
- `ROADMAP.md` — the overall learning roadmap
- `STATUS.md` — day-by-day progress tracker
- `problem_solving.md` — general problem-solving notes
