  ## 🔹8. Tuples

- Immutable sequence (cannot modify after creation)
- Created using () or comma (,)
- Single element tuple needs comma → (5,)
- Supports indexing, slicing, traversal

### Operations:
- Concatenation (+)
- Repetition (*)
- Membership (in)

### Methods:
- count()
- index()

### Key Concepts:
- Tuple is immutable but can contain mutable elements (like list)
- Faster than list (less overhead)
- Can be used as dictionary keys
- Tuple vs List → use tuple for fixed data

---

## 🔹 Tuple Unpacking

- Assign multiple values at once → a, b = (1, 2)
- Swapping → a, b = b, a
- Star unpacking → a, *b, c
- Ignore values → _
- Loop unpacking → for a, b in pairs
- Nested unpacking supported

---

## 🔹 Named Tuples

- Created using collections.namedtuple
- Access using dot notation (obj.name)
- Improves readability
- Immutable like tuple
