# 🧠 0. Core Concept: What is an Array (List)

From basics 

## Key Properties:

* Ordered
* Mutable
* Indexed (0-based)
* Can store multiple values

---

# 🔥 1. Traversal (MOST BASIC PATTERN)

## 🧠 Pattern:

Iteration over list

## 💻 Code:

```python
for i in nums:
    print(i)
```

## 🔑 Concept:

* Access each element
* Used in EVERY problem

## ⏱ Complexity:

O(n)

---

# 🔥 2. Find Maximum Element

## 🧠 Pattern:

Comparison / Tracking

## 🪜 Logic:

1. Assume first element as max
2. Compare with each element
3. Update max if bigger found

## 💻 Code:

```python
max_val = nums[0]

for i in nums:
    if i > max_val:
        max_val = i
```

## ⚠ Mistakes:

* ❌ Using `max = 0` (fails for negatives)
* ❌ Wrong comparisons in dry run

## ⏱ Complexity:

O(n)

---

# 🔥 3. Find Minimum Element

## 🧠 Pattern:

Same as max (reverse condition)

## 💻 Code:

```python
min_val = nums[0]

for i in nums:
    if i < min_val:
        min_val = i
```

## ⚠ Mistakes:

* ❌ Using variable name `max`
* ❌ Wrong initialization

---

# 🔥 4. Count Even Numbers

## 🧠 Pattern:

Counting + Condition

## 🪜 Logic:

* Check each element
* If divisible by 2 → count++

## 💻 Code:

```python
count = 0

for i in nums:
    if i % 2 == 0:
        count += 1
```

## ⏱ Complexity:

O(n)

---

# 🔥 5. Check Element Exists

## 🧠 Pattern:

Linear Search

## 🪜 Logic:

* Compare each element with target
* If found → stop early

## 💻 Code:

```python
found = False

for i in nums:
    if i == target:
        found = True
        break
```

## 🔑 Key Concept:

* Early exit optimization

## ⏱ Complexity:

O(n)

---

# 🔥 6. Sum of All Elements

## 🧠 Pattern:

Accumulation

## 🪜 Logic:

* Add each element to total

## 💻 Code:

```python
total = 0

for i in nums:
    total += i
```

## ⚠ Mistake:

* ❌ Skipping dry run (VERY IMPORTANT)

## ⏱ Complexity:

O(n)

---

# 🔥 IMPORTANT ADDITIONS (MISSED / UPGRADE)

---

## 🔹 7. Index vs Value Loop

### Value-based:

```python
for i in nums
```

### Index-based:

```python
for i in range(len(nums))
```

👉 Use index when:

* Need position
* Need modification

---

## 🔹 8. Dry Run (CRITICAL SKILL)

👉 Always track:

* Variable changes
* Array updates
* Loop iterations

Example:

```text
nums = [1,2,3]

total = 0
→ total = 1
→ total = 3
→ total = 6
```

---

## 🔹 9. Edge Cases (ALWAYS THINK)

* Empty list → []
* Single element → [5]
* Negative numbers
* All same values

---

## 🔹 10. Time Complexity Basics

| Pattern     | Complexity |
| ----------- | ---------- |
| Single loop | O(n)       |
| Nested loop | O(n²)      |

---

## 🔹 11. Naming Convention (IMPORTANT)

❌ Avoid:

```python
max, sum, list
```

✅ Use:

```python
max_val, total_sum, nums
```
